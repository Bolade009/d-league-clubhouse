How to Join D League Clubhouse
Step-by-step for new managers
1. Join the official FPL league
  • Receive the private league code from the Commissioner (WhatsApp/group).
  • Go to fantasy.premierleague.com and join using the code.
  • Note your exact FPL Club / Team Name.
2. Request access to Clubhouse
  • Click REQUEST ACCESS on this site.
  • Enter: Full Name, Email, FPL Club Name.
  • FPL Team ID is optional (admin will set the accurate ID).
3. Get approved & login
  • Admin approves and sends you an Access Code.
  • Login with your Email + Access Code.
4. Update Bank Details
  • Click Update Bank Details (required to receive automatic payouts).
5. Pay & get started
  • Pay for FPL and/or UCL via Paystack.
  • Use the dashboard, lineups, standings, ledger, challenges & beefs.
  • When you have balance, use Request Payout to Bank.
Questions? Message the commissioner. Everything is transparent and recorded via Paystack webhooks + FPL public APIs.
